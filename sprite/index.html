Download sprite

Use the sprite

Copy bootstrap-icons.svg into your site, then use the icon filename as the fragment identifier.

HTML
<svg class="bi" width="32" height="32" fill="currentColor" aria-hidden="true">
  <use href="/bootstrap-icons.svg#heart-fill"></use>
</svg>

Cross-origin use

Serve the sprite from the same origin as the page. Browser security restrictions can prevent external <use> references across domains.

For a standalone image with alt text, use an individual SVG from/assets/icons/ instead.
